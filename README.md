# Provador 3D — site publicado

Ramo só com os arquivos do site do Provador 3D (Sofá Outlet e Decorart Ambientes).
O Cloudflare Pages publica este ramo automaticamente.

- `index.html`: escolha da loja
- `sofa-outlet.html` e `decorart.html`: provador de cada loja
- `*.glb`: modelos 3D; `amb-*`, `foto-*`, `tec-*`, `tex-*`: fotos de ambiente, produtos e tecidos
